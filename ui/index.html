Prometheus endpoint
Where Prometheus connects to this exporter.
01

            

              
Default: 127.0.0.1 (loopback). Address the exporter listens on, not the Repeater API host. Use a reachable LAN/VPN address only when remote Prometheus access is needed. The metrics endpoint has no application-level authentication; restrict access with your network or firewall.

              
Default: 9109. Exporter listening port; range: 1024–65535 for the unprivileged plugin. Choose an unused port and match it in your Prometheus scrape target.

              
Default: /metrics. HTTP path Prometheus scrapes. Must start with / and be at most 128 characters; no query, fragment, double slash or .. segments. /healthz is reserved for health checks.

              
Default: 30 seconds; range: 5–3600. Interval between background collection cycles. Prometheus scrapes read the cached snapshot rather than starting a new collection. Must be greater than the collection timeout.

              
Default: 10 seconds; range: 0.5–60. Timeout used for Repeater API requests. Must be strictly less than the collection interval. This is not the Prometheus scrape interval or a guarantee that the complete multi-endpoint collection finishes within this time.

            

            

          


          

            
openHop Repeater /api/stats
The required stats endpoint supplies telemetry; additional mesh endpoints are collected on a best-effort basis.
02

            
Default: enabled. Collect telemetry from the configured Repeater API, including required /api/stats and additional best-effort mesh endpoints. Disable to stop Repeater collection; the exporter and plugin runtime metrics remain available.

            

              
Default: http. Protocol for the Repeater API connection, not the exporter listener. Choose https when the Repeater endpoint supports TLS; certificate verification is controlled below.

              
Default: 127.0.0.1. Hostname or IP of the Repeater API, without a scheme or path. Loopback means the plugin’s own host/container network namespace. For a separate Repeater host or container, use a reachable address.

              
Default: 8000; range: 1–65535. Repeater API port, not the exporter port. Match the actual Repeater listener or HTTPS reverse-proxy port.

              
Default: /api/stats. Required Repeater telemetry endpoint. Must start with / and be at most 128 characters; no query, fragment, double slash or .. segments. Additional mesh endpoints remain best-effort.

              
Optional when Repeater read-only access is allowed. Otherwise use a Repeater API key. Sent as X-API-Key, not as a Bearer header; an accidental leading Bearer prefix is stripped. Saved in plugin configuration, but never exported as a metric or runtime dashboard value. Use HTTPS for untrusted networks.

              
Default: enabled. Validate the Repeater HTTPS certificate. Has no effect for HTTP. Keep enabled for normal use; disabling skips certificate checks and permits impersonation. Prefer installing a trusted certificate rather than disabling verification.
